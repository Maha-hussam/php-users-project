# PHP User Management System

A simple user management system built with PHP, MySQL, HTML, and PDO.

## Features

- Home page
- Add User
- Users List
- Create users
- Read users from the database
- Form validation
- PDO database connection

## Requirements

- XAMPP
- PHP 8.0 or later
- MySQL
- Composer

## Project Setup

### 1. Clone or copy the project

Place the project inside the XAMPP `htdocs` directory:

```text
C:\xampp\htdocs\php-user-management
